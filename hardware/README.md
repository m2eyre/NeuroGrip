# Hardware

- `stl/`: the four printable parts, already in print orientation. Print guide: [docs/printing.md](../docs/printing.md)
- `cad/python/`: parametric Python model. Regenerate STLs with `python export_stl.py`. Guide: [docs/cad.md](../docs/cad.md)
- `cad/solidworks/`: SolidWorks VBA macro that builds the parts and a movable assembly

Assembly: [docs/assembly.md](../docs/assembly.md) · Wiring: [docs/wiring.md](../docs/wiring.md)
