# g.tec recordings go here

`--muscle` and `--dataset` replay g.tec's **SSVEP LED dataset**. Put these four files in this folder:

```
subject_1_fvep_led_training_1.mat
subject_1_fvep_led_training_2.mat
subject_2_fvep_led_training_1.mat
subject_2_fvep_led_training_2.mat
```

The data was recorded by g.tec medical engineering GmbH and provided to Hack the Nest 2026 participants (g.tec track). If the files aren't in this repo, get them from g.tec or the event organisers.

What the data is and how NeuroGrip uses it: [docs/gtec-data.md](../../../docs/gtec-data.md).
